# Déroulé d'atelier

Format de référence : **3 h 30**, 3 à 5 équipes de 3 à 5 personnes, un facilitateur. Une version courte (2 h) est proposée en fin de page.

## Avant l'atelier (J-7 à J-1)

- [ ] Choisir le scénario : IT (NeoTitan, HealthNova), sourcing (Mirage Offshore), industriel (Vénissieux), expansion (Maison Dumas) ou un scénario généré dans le Studio et validé par le contrôle d'équilibrage.
- [ ] Lire la **note pédagogique** du cas (Docs & kit, PIN animateur) : objectifs, tensions, agendas cachés, pièges, chemin gagnant et questions de débriefing propres au cas.
- [ ] Vérifier le moteur IA dans **Réglages** (fournisseur cloud recommandé en salle : les modèles locaux sont lents).
- [ ] Créer la session avec le nombre d'équipes et une durée de trimestre (20 à 25 min recommandées).
- [ ] Générer les liens d'équipe (**Invitations atelier**) et les envoyer.
- [ ] Faire lire le **manuel du joueur** et le dossier de cas aux participants.
- [ ] Préparer le **questionnaire avant atelier** (voir protocole pilote).

## Version courte (2 h)

Tutoriel 10 min, quatre trimestres de 15 min avec résolution immédiate, debrief 30 min. Recommandée avec un scénario de difficulté INTERMEDIATE.

## Pendant la partie : les leviers du facilitateur

- **Minuteur** : pause et reprise depuis le cockpit.
- **Annonces** : message à toutes les équipes.
- **Crise injectée** : à utiliser une fois, pour tester l'adaptation (elle frappe immédiatement et remplace le dilemme du trimestre).
- **Démo commentée** : à projeter en ouverture pour montrer deux stratégies opposées.

## Après l'atelier

- Exporter le debrief (JSON et Markdown) depuis le cockpit.
- Réinitialiser la session si elle doit être rejouée : la partie est archivée dans le debrief.
- Analyser les questionnaires avant / après (protocole pilote).
